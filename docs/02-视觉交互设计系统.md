# 02 — 视觉交互设计系统：「深夜工位」3D 导览

> **本文件是 `01-内容结构文档.md` 的「视觉 + 交互层」补充，二者共同构成喂给 Claude Code 的完整输入。**
> **核心创意（来自你）**：首页是一个深夜游戏工位，台灯亮起照亮桌面，鼠标移动高亮物品显示标题，点击进入不同页面。
> **本文件做三件事**：① 把你口述的创意**补成完整、可执行的设计系统**；② 给出**每个物件/动效去哪找素材**；③ 给出**怎么发给 Claude Code 的分包 Prompt**。

---

## 0. 一句话设计纲领

> **「一张深夜工位 = 一个 3D 导航菜单。」**
> 物件即入口，Hover 浮起 + 标签，点击触发镜头运镜进入对应板块。
> 保持「理性（工程）× 感性（艺术）」的轻艺术基调（来自 01 §1），用**暗色 + 暖光 + 游戏化**表达。

---

## 1. 场景设定（世界观）

| 维度 | 设定 | 说明 |
|------|------|------|
| 视角 | **等距 2.5D（Isometric）**，微倾斜俯视，固定机位 | 契合你「2.5D 渲染」技术标签，本身是能力展示 |
| 时间 | 深夜（暗环境），唯一光源 = **台灯暖光** | 台灯 = 主题切换彩蛋，也是视觉焦点 |
| 氛围 | 暗色桌面 + 暖光 Rim Light + 微弱屏幕光 | 像深夜 coding 的真实工位 |
| 色彩 | 桌面 `#1a1d24` / 深灰 `#0f1115` / 青 `#00d9ff` / 紫 `#a855f7` / 暖光 `#ffb974` | 青紫点缀，暖光主照明 |
| 美术 | **轻拟物 + 像素描边**（不是写实 3D，避免 AI 味） | 有温度、有记忆点、符合「轻艺术」 |
| 微叙事 | 桌面「正在工作中」：咖啡冒热气、代码在跑、手柄连线 | 暗示「活的人」，不是陈列柜 |

### 1.1 开场导览剧本（GSAP 驱动，可写成自动导览）

教程作者强调「摄像机聚焦和运镜逻辑」——这段开场**既是导航，也是你的能力广告**：

```
① 黑屏 → 台灯「啪」亮起，暖光扩散照亮桌面        [GSAP 光照动画]
② 镜头从桌面一角缓慢推近（缓动运镜）             [ScrollTrigger / Camera]
③ 物件逐个「弹簧弹出」落到桌面                   [GSAP CustomEase]
   顺序：显示器 → 键盘 → 手柄 → 文件夹 → 本子 → 咖啡杯
④ 显示器屏幕亮起，打字机打出名字 + 定位          [Typed.js]
⑤ 屏幕弹出一行提示：「拖拽 / 滚动 探索工位」      [自动导览结束]
⑥ 咖啡热气循环飘动（idle）                       [CSS animation]
⑦ 鼠标移入物件 → 浮起 + 标题浮现 + 轻微旋转      [GSAP hover]
⑧ 点击物件 → 镜头聚焦 → 页面过渡                [GSAP + Barba.js]
```

> ⚠️ **自动导览只播一次**（localStorage 记录），之后进首页直接是静态工位，避免打扰。

### 2.1 物件优先级（MVP 先做什么）

> 教程作者教训：**初版一定粗糙，先保核心物件，彩蛋后补。** 你按这个顺序做，不会贪多烂尾：

| 批次 | 物件 | 优先级 | 说明 |
|------|------|--------|------|
| **P0（必须有）** | 显示器、手柄、电脑桌面（作品/博客文件夹）、纸质文件夹、本子、台灯 | ✅ 首版必做 | 对应 01 全部核心路由 |
| **P1（应该做）** | 键盘、工牌/Logo、咖啡杯 | 第二版 | 增强沉浸 |
| **P2（彩蛋）** | 耳机、手办、贴纸、散落代码纸条 | 最后 | 趣味与个性 |

## 3. 三个核心交互界面（你口述 + 补全）

### 3.1 🎮 手柄 → About：游戏化介绍界面（**你的创意，重点补全**）

> 你说：「点击手柄进入类似于游戏的界面，使用 A/D 或鼠标移动操控小人从左到右看个人介绍」

**设计定稿**：
- 点击手柄 → 镜头推入 → 进入一个**横版 2D 小场景**（像素小人 = 你自己）
- **操控**：`A/D` 或 `←/→` 或**鼠标移动**控制小人左右移动（三种输入并存，教程作者强调「手感优化」，这里正好展示）
- 场景从左到右分 **3-4 个「展板/屏幕」**，小人走到展板前停下，展板亮起播放内容：
  - 展板 1：**我是谁**（一句话定位 + 头像）
  - 展板 2：**我的旅程**（时间轴：5岁执柄 → 战双 → 辽宁大学 → 现在）
  - 展板 3：**核心竞争力**（性能优化 / 架构 / 数据驱动）
  - 展板 4：**教育背景**（辽宁大学 + 主修课程）
- **地面**可做成「能力条」或「代码滚动」的视觉隐喻
- 右上角：**ESC 返回工位**

> 💡 **这个界面的价值**：面试官能「玩」你的网站 30 秒，记忆点拉满；同时展示你**横版角色控制、输入系统、状态机**的真实工程能力——和 01 §4.1 的技能完全呼应。

**实现建议**：用 **纯 2D Canvas 或轻量引擎（PixiJS / Phaser）** 嵌在 Astro 页面里，不要为了它把整个站改成游戏引擎。小人精灵图可用像素素材。

### 3.2 💻 电脑桌面 → Works + Blog：桌面拟物操作系统

> 你说：「点击进入之后显示桌面（作品和项目文件夹、博客个人 Logo），通过桌面风格图标进入，可以复用我写过的代码」

**设计定稿**：
- 点击「电脑屏幕」或桌面图标 → 进入一个**拟物操作系统桌面**（像 WebOS / macOS 拟态）
- **桌面图标**：
  - 📁 `Works`（作品）→ 双击打开 → 作品列表（流浪尸潮 / 不绘鸽 / 智联传感 / 气垫导轨 + 美术作品）
  - 📁 `Blog`（博客，贴着你的个人 Logo 贴纸）→ 双击 → 博客列表
  - 📄 `Resume.pdf` → 双击 → 打开 PDF 预览 / 下载
  - ⚙️ 右上角菜单 → Skills / Theme / 返回工位
- **窗口系统**：双击图标打开「可拖拽、可缩放、可最小化」的窗口（教程作者用「文件夹、立体书交互」，Reactbits 有现成源码）
- **复用你写过的代码**：这里的窗口/拖拽/文件管理器逻辑，可以复用你在「流浪尸潮」或「不绘鸽」里写过的 UI 代码——**这正好是作品集最好的旁证**

### 3.3 📂 纸质文件夹 → Awards：可翻页证书墙

- 点击桌面「纸质文件夹堆」→ 镜头推近 → 进入**证书/奖状翻页视图**
- 按 01 §6 分组：**竞赛获奖（省级+） / 奖学金 / 证书 / 软著**
- 交互：左右翻页、点击放大、按类别筛选（校级可隐藏，对应 01 §6.2）
- 视觉：纸面质感 + 轻微阴影 + 翻页动效（CSS 3D / GSAP）

### 3.4 📓 本子（Links）→ Contact + 外链

- 点击本子 → 翻开 → 左页联系方式（邮箱/微信/手机），右页外链图标（GitHub / B站 / ArtStation / 站酷）
- 每条带「复制」按钮 + 点击跳转

## 4. 物件交互状态机（喂给 AI 的精确规格）

每个物件统一三种状态，**AI 实现时保持一致**：

```
[IDLE 空闲]  ──鼠标进入──▶  [HOVER 高亮]
   │                            │
   │                            ├─ 浮起(Y+8px) + 轻微旋转(2°)
   │                            ├─ 标题标签淡入（打字机）
   │                            ├─ 发光边缘（青/紫）
   │                            │
   │                        鼠标点击
   │                            │
   │                            ▼
   │                       [ACTIVE 激活]
   │                            │
   │                            ├─ 镜头聚焦该物件
   │                            ├─ 台灯光照跟随
   │                            └─ 页面过渡动画
   │                            │
   └──────── 过渡结束 ──────────┘
```

## 5. 技术选型（对应 01 §2 路由 + 教程推荐）

| 层级 | 技术 | 用途 |
|------|------|------|
| 框架 | **Astro** | 路由（01 §2 全部页面）、Markdown 博客、静态产物 |
| 3D 工位 | **Three.js / react-three-fiber** | 等距 2.5D 工位场景、物件、镜头运镜 |
| 2D 手柄界面 | **Phaser / PixiJS** | 横版小人、输入控制、展板 |
| 动效 | **GSAP + ScrollTrigger** | 运镜、弹出、光照、idle（教程同款） |
| 窗口/拖拽 | **Reactbits 源码复用** | 桌面窗口系统（教程作者推荐源） |
| 3D 物件建模 | **img2three.js (imgr skill)** | 手柄/文件夹等立体质物件（教程同款） |
| 托管/后端 | **Cloudflare Pages + Pages Functions** | 部署 + 兼容后端（评论/表单/API） |
| 域名 | **Porkbun** → DNS → **Cloudflare** | 域名 + CDN + HTTPS |

> 💡 **架构建议**：3D 工位只在**首页**加载（重），进入二级页面后切回**普通 DOM/CSS**（轻）。用 Astro 的「群岛架构」按需 hydrate，避免全站 Three.js 拖慢性能——这正好呼应你在 01 §4.1 里的「性能优化」能力。
