## 0. 一句话架构

**Astro 5 多页面站点，重型库按需加载（群岛架构）：**

- 首页 `/` —— 原生 Three.js（**不用** react-three-fiber）画 2.5D 等距深夜工位
- 关于 `/about` —— Phaser 碰旗弹卡游戏（横版小球碰旗弹出四章图文卡片）
- 桌面 `/desktop` —— 原生 JS + GSAP 的四入口选择台（**不用** React）
- 二级页（作品/证书/博客/联系）—— Astro 组件 + 原生 DOM/CSS，零重库

## 2. 关键架构决策

1. **群岛架构（按需加载）**：Three.js 只进首页 chunk，Phaser 只进 /about chunk，二级页不背任何重库。判定标准：`astro build` 后各页面 JS 独立分包。
2. **3D 用原生 Three.js**：项目规模小，R3F 的声明式抽象层是纯负担；直接用 `THREE.OrthographicCamera` 做等距视角。
3. **`/desktop` 用原生 JS + GSAP**：不用 React/Reactbits。原来的手写窗口系统已按 2026-09-04 决策删除，改成「选择台 → 单张弹出详情」（见 `src/scripts/desktop/desktop.ts`）。
4. **数据驱动**：所有内容集中在 `src/data/*.ts` 的 TS 对象里，页面只读数据渲染，改内容不改组件。
5. **样式统一 Tailwind v4**：设计 token（配色/圆角/阴影）在 `@theme` 里定义，不引入 SCSS。

`category` 取值：`"省级及以上" | "校级院级" | "待补" | "证书"`。⚠️ **奖学金类别已整体删除**。

`DeskObject` 接口：`id / mesh / title / route`。`mesh` 是 `room_full.glb` 里的节点名（`obj_*`），`desk.ts` 靠它在模型中定位可点物件；`route` 的特殊值 `theme`（切昼夜）与 `coffee`（彩蛋）不跳路由。坐标 / 颜色 / 尺寸字段随占位几何体一起退役——这些信息现在全部来自模型本身。映射见 §3。

### 5.5 aboutGame.ts —— 游戏化 About 数据
`GameBoardData` 接口：`id / index / title / kicker / tagline? / cover / gallery? / reel? / lines / subtitle? / scrollTexts? / cta?`。4 章（`start / turning / now / ending`），每章带封面图 + 图文数组：`gallery`（竖幅拍立得图墙）、`now` 章额外有横向滚动 `reel` 画作集、`ending` 章有滚动金句 `scrollTexts` + 联系 CTA。常量：`WORLD_WIDTH=2400`、`FLAG_X_START=420`、`FLAG_GAP=560`、`PLAYER_START_X=72`、`TRIGGER_RANGE=64`。

## 6. 关键实现规范（详见 02 §5）

- **悬停状态机**：物件三态 `IDLE / HOVER / ACTIVE`，GSAP 统一驱动（`src/scripts/desk.ts`）。HOVER = 沿世界「上」浮起 + 放大 2.8% + 青色自发光；ACTIVE = 镜头飞近 + 渐黑跳转（D5）。物件在模型里带旋转和非均匀缩放，浮起向量由 `liftInParentSpace()` 把世界位移换算到父空间，不能直接改 local Y。
- **模型加载**：`GLTFLoader` 读 `/models/room_full.glb`（无 Draco），按 `objects.ts` 的 `mesh` 名取物件。glb 里 58 个材质有 10 个被多物件共用，取件时**逐物件克隆材质**，否则 hover 发光会串到别的物件上。
- **视角摇晃**：`pointermove` 归一化到 [-1,1]，在 rAF 里 lerp（系数 0.055）平移正交相机，幅度 = 工位半径 × 0.22；仅 `pointer: fine` 且非 `prefers-reduced-motion` 时启用。
- **首页图层顺序**：WebGL 用 `alpha: true` + 不设 `scene.background`，画布透明；场景底色改由 `body` 背景提供（随 `data-theme` 用 CSS 过渡切换）。`#hero-type`（背景排版大字）在 `z-index: 0`，`#desk-scene` 在 `z-10`，房间挡住大字中段形成前后空间感；大字随鼠标反向平移 26px 做视差。取景 `FIT_IDLE = 1.5` 是为了给房间四周留出露字的余量。
- **背景大字排版**：文案取 `profile.heroLines`（不含真名），每行字号由 `fitHeroType()` 实测 `scrollWidth` 回推，撑满整行宽；CSS 里按字符数估算的字号只是无 JS 时的兜底，粗黑体字宽因系统而异，纯估算会切掉行尾字母。
- **悬停提示只有一处**：物件的标题只由热点圆点的 `.hotspot-label` 展开（鼠标碰圆点 = `:hover`，鼠标碰 3D 物件 = `desk.ts` 给圆点加 `.is-hot`）。早期那个跟随鼠标的 `#hover-label` 会和圆点标签重叠，已删除。
- **热点圆点 = 导航菜单**：只有 `route` 以 `/` 开头的 4 件（电脑 / 手柄 / 文件堆 / 日记本）有圆点；台灯（切昼夜）和咖啡（彩蛋）是就地生效的动作，不进菜单，仍可点，靠 3D hover 发光被发现。`DeskItem.hotspot` 允许为 `null`，投影与事件绑定都跳过它们。
- **贴在 3D 上的 2D 元素**：热点圆点每帧从世界坐标重投影，否则镜头摇晃或窗口缩放后会与物件错位。开场第 ④ 步原先还往显示器上投一行「姓名 · 职位」（`#screen-text`），压在画面中间太抢眼已删除，只保留亮屏；身份信息由背景大字与 `/about` 承担。
- **开场剧本**：①-⑧ 步骤，标记在**剧本播完**后才写入（中途刷新不会跳过）。⚠️ 2026-09-04 用户决策把「每个浏览器只播一次」改成**「每个会话播一次」**：标记从 `localStorage` 换到 `sessionStorage["lszbf:intro:played"]`，同一标签页内刷新或跳页回来会跳过，关掉标签页再进就重播一次（02 §1.1 正文按规则不改，实现以此为准）。另外带 `?intro` 进首页可强制重播，调动效时不用手动清标记。老访客浏览器里遗留的同名 `localStorage` 项已不再读取。
- **主题切换**：台灯物件切换 `localStorage["lszbf:theme"]`；`TransitionOverlay.astro` 的 inline 脚本在首屏绘制前把 `data-theme` 写到 `<html>`，四个页面入口都引了它，所以跨页保持不闪色。黑夜 = 台灯 PointLight + 弱冷 Ambient；白天 = HemisphereLight + DirectionalLight 暖色，切换走 GSAP 过渡无突变。
- **移动端降级**：`matchMedia("(pointer: coarse)")` 或 `clientWidth < 768` → 静态 DOM 菜单，不加载 3D。JS 判定降级或模型加载失败时给 `<html>` 加 `.is-fallback`，CSS 据此露出菜单（只靠 `max-width:767px` 媒体查询会漏掉「触屏 + 宽屏」设备而白屏）。
- **`/about` 碰旗弹卡**（`src/scripts/game/`，Phaser 3）：横版世界铺 4 面小旗（`Flag`，`board.ts`），黄色小球（`Player`，`player.ts`）靠 A/D 或 ←/→ 移动、鼠标只转眼睛（`input.ts`）。碰到旗子（`game.ts` `updateFlags()`，距离 < `TRIGGER_RANGE`）就弹出一张图文卡片（`.about-board`，DOM 由 `renderPanel()` 按章 `id` 分支拼 `start/turning/now/ending` 四种版式），小球 `hop()` 一下 + `cardHitFx` 火花。第 4 面（`ending`）触发 `startCelebrate()`：烟花循环 + 小球庆祝弹跳，并进入 `about-browse` 模式——隐藏游戏层、滚轮左右翻阅各章（`bindWheel()`）；CTA「联系我 →」走 `navigateWithTransition`。ESC 回 `/`。画布透明、背景奶油黄配色，样式在 `global.css` 的 `.about-*`。
- **`/desktop` 选择台的三段动作**（`src/scripts/desktop/desktop.ts`）：
  1. 图标 → 待命位：FLIP。先量原位，再把图标 `appendChild` 到 `.dt-stage`（脱离整排列表，否则跟着列表一起淡出）、加 `.is-active`（CSS 定到左侧待命位），量末位后补一段位移。整排列表靠 `.dt-stage.is-open .dt-cards` 变 `position:absolute; opacity:0` 退出布局，并对列表加 `inert` 防止键盘还能 tab 进去。换入口时先 `park()` 上一枚，否则两枚图标会叠在待命位。
  2. 文件夹里的作品：FLIP 从 `.dt-folder-pocket` 的屏幕位置错峰弹到网格位（红文件夹 4 个项目、黄文件夹美术四类）。参考 codepen `d3adr4bbit/RwvmGzV` 的观感重建——⚠️ 原 pen 源码抓不到（CodePen 有 Cloudflare 校验、作者仓库里没有 `script.js`），不是逐帧复刻。
  3. 换页：点 Logo 走「盖色」进 `/blog`，点摊开的项目封面走「整页上弹」进 `/works/[slug]`，跑完再 `location.href`。这些链接带 `data-no-transition`，让 `transition.ts` 的全站渐黑放行；离场前写 `sessionStorage["lszbf:dtx"]`，`TransitionOverlay.astro` 的 inline 脚本在首屏前读成 `<html data-enter>`，目标页用 `enter-rise` / `enter-veil` 接住（keyframes 在 `global.css`，同时挂 `body > main` 与 `body > article`，因为项目详情页的内容根是 `<article class="pd">`）。
- **`/desktop` 三个图标是 CSS 3D 实体，不是贴纸**（2026-09-04 用户要求「建立真实的 3D 空间、别做成扁的」）：透视给在 `.dt-card`（`perspective: 900px`），物件本体 `.dt-art > .dt-depth` 开 `transform-style: preserve-3d`，内部各层用 `translateZ` 拉开距离拼出厚度。文件夹按用户给的参考图做**三层**：① 后板 −24px，色更深（`color-mix(tone 84%, #2b1008)`）、比前袋窄，左上角带同色标签页；② 夹在中间的作品 −14~−2px，竖幅白边纸样，绕袋口（`transform-origin: 50% 100%`）扇形散开，横向跨度刻意收窄到 22%~86%，好让后板的左右边和标签页从纸缝里露出来；③ 前袋 +26px、最亮最宽，`rotateX(-6deg)` 微微敞口，顶上再压一道浅色亮边当板材厚度。Logo 是粉白渐变圆角方片（6 层同尺寸方块后退拼侧壁）+ 铺满的白色 Z（字号 `66cqi`，跟着方片长）。简历纸叠已删。
  ⚠️ 前袋的渐变必须是竖直的 `180deg`：斜向角度在这种宽扁盒子上会显出一道对角折痕。`desktop.ts` 按鼠标在图标内的相对位置转 `.dt-depth` 的 `rotationX/rotationY`（幅度只有 ±9°/±10°，再大鼠标划到角上物件会正对镜头、立体感反而没了），静止姿态四枚各差 5° 侧转角。这一页**不引 Three.js**（重库只进首页，见 §2 决策 1）。
  ⚠️ `filter` 在这一套里有两处坑，都踩过：① `.dt-card` 上原来的 `filter: drop-shadow` 已删——`filter` 会把 3D 子层扁平化成一张图；② 地面投影 `.dt-ground` 起初用 `filter: blur(9px)`，带 `filter` 的元素会被排除在 3D 深度排序之外、改按 DOM 顺序压到最上层，于是投影糊在袋身上像一道斜折痕，现改成 `radial-gradient` + `translateZ(-30px)`，并且在 `EntryArt.astro` 里写在 `.dt-depth` **之前**。另外 `.dt-depth` 及其祖先都不能设 `overflow` 非 `visible`，同样会压平。
- **文件夹里的缩略图**：红文件夹夹 `projects.ts` 的封面、黄文件夹夹 `art.ts` 的分类色块（`EntryArt.astro` 里 `thumbs.slice(0, 4)`，当前两边各 4 条所以全夹进去，多了前袋遮不住），由 `desktop.astro` 算好传给 `EntryArt.astro` 的 `thumbs`。摊开时这几张淡出（东西被拿出来了，文件夹就空了），`park()` 关闭时再淡回来；`?#art` 这类不带动画的直达路径直接 `gsap.set(opacity:0)`。
- **不要用 `await` 等 GSAP 动画再改 DOM**：标签页被节流（或后台渲染）时 rAF 会近乎停摆，`await tween` 永远不 resolve，点击就整个失灵。开合只用 `setTimeout` 上 340ms 的锁，动画一律 fire-and-forget。
- **`/desktop` 文件夹开合**（2026-09-04）：细指针悬停红/黄文件夹，卡片从袋面左下沿弧线扇到上方；指针离开文件夹和扇面后收回。触屏没有稳定悬停，改点一下开合。`Esc` 也能收。开合不再写 hash / `pushState`（悬停态不该进历史）。页面左上角只有一个无字箭头，回 `/`。
