## 1. 网站定位与风格基调

- **定位**：真正的个人网站，非纯简历页。开发向为主，美术作品为辅，叠加博客与外链跳转。
- **风格基调**：轻艺术风格（`轻艺术`）——大量留白、柔和低饱和配色、克制的排版；以"理性（工程）× 感性（艺术）"为气质，与"物理 + 艺术"的复合背景呼应。
- **首页创意**：深夜游戏工位 3D 导览（暗色 + 暖光 + 游戏化，等距 2.5D，轻拟物 + 像素描边）。
- **导航语言**：中英混排，主中文。
- **备注**：具体配色 / 字体在 UI 设计阶段定稿，本文档只定义"内容与信息架构"。
